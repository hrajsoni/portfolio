# Harshit Raj — Interactive 3D Mechanical Keyboard Developer Portfolio

An immersive, interactive developer portfolio engineered with **Next.js 16**, **React Three Fiber**, and **Tailwind CSS v4**. Features a real-time 3D mechanical keyboard hero scene with tactile audio, seasonal themes, kinetic typography, bento skill showcase, and an illuminated cybernetic experience timeline.

👉 **[Live Portfolio Demo](https://hrajsoni.github.io/portfolio)** &nbsp;|&nbsp; **[Live D2C Brand Store (Old Loom)](https://oldloom.vercel.app/)** &nbsp;|&nbsp; **[LinkedIn](https://www.linkedin.com/in/harshitrajsoni/)** &nbsp;|&nbsp; **[GitHub](https://github.com/hrajsoni)**

---

## Key Highlights

- **Interactive 3D Mechanical Keyboard** — A fully interactive mechanical keyboard rendered with React Three Fiber and Three.js. Keys respond to pointer interactions and live typing with physical spring travel, acoustic click feedback, and emissive neon lighting.
- **Kinetic Typography & Metallic Shimmer** — 3D perspective letter-by-letter entrance animations, continuous liquid-metal gradient shimmer, ambient breathing backplate aura, and tactile hover bouncing on every character.
- **Interactive Tech Arsenal Bento** — A responsive 15-skill keycap grid with illuminated brand containers, proficiency categories, dynamic taglines, and synchronized 3D keyboard interactions.
- **Cybernetic Experience Timeline** — Illuminated vertical spine with traveling neon laser pulses, mechanical milestone nodes, obsidian glassmorphism cards, and high-impact metric badges (`+22% AOV Lift`, `95+ Mobile Speed`, `RBAC + JWT`, `Real-Time Geolocation`).
- **Dynamic Seasonal Theming** — Four distinct palettes (Winter, Spring, Summer, Autumn) that instantaneously restyle the DOM and 3D scene lighting via CSS custom property tokens.
- **Project Case Studies & Modals** — High-contrast frosted glass cards with interactive image carousels, status badges, tech chips, and live links.
- **Smooth Scroll & Micro-Interactions** — Powered by [Lenis](https://github.com/darkroomengineering/lenis) for buttery smooth scrolling with reveal animations.

## Getting Started

### Prerequisites

- **Node.js** 20+
- **npm** 10+

### Local Installation

```bash
# Clone the repository
git clone https://github.com/hrajsoni/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```
